# Kingdomapps — prévia de hotsite: Fornezza Pizzaria

Prévia interna (Kingdomapps). A página raiz é um gate protegido por código; após o desbloqueio mostra 2 versões
visuais do mesmo site institucional (mesma marcação e comportamento, muda só a skin).

- Gate: https://fcwwebsites.github.io/kingdomapps-hotsite-fornezza/
- `/v1/` — Trattoria calorosa
- `/v2/` — Editorial clássico

Cardápio exibido é **simulado** (sinalizado na página). Fotos de banco só como ambientação — créditos em `assets/CREDITS.md`.

Pages: branch `main`, pasta `/`. Prévia local: `python3 -m http.server 8765`.
